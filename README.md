# Сайт SalfVisuals

Статический сайт: `index.html` + `style.css` + `script.js` + `version.json`.
Никакого сервера/бэкенда не нужно — просто набор файлов.

## Важно — что тебе нужно сделать самому

**У меня нет реального собранного `.jar` файла мода** — я всё это время присылал
тебе только исходный код, который ты сам собирал через `gradlew build`.
Чтобы кнопка "Скачать" на сайте реально работала:

1. Собери мод у себя (`gradlew clean build`, как мы уже делали)
2. Возьми файл `build/libs/salfvisuals-0.1.0.jar`
3. Переименуй в `salfvisuals-0.1.0-beta.jar` (или поправь имя в `version.json`, см. ниже)
4. Залей его в корень репозитория (рядом с `index.html`) — GitHub через веб-интерфейс
   не всегда нормально принимает загрузку целых папок, поэтому проще класть jar
   прямо в корень и указывать в `version.json` просто имя файла, без "downloads/"

Без этого шага кнопка будет вести в никуда.

## Как проверить локально

Открывать `index.html` двойным кликом **не сработает** — браузер блокирует
`fetch()` для локальных файлов (`file://`). Нужен простой локальный сервер:

```
cd site
python -m http.server 8000
```

Потом открой `http://localhost:8000` в браузере.

## Как выложить в интернет (бесплатно) — GitHub Pages

1. Создай репозиторий на GitHub, залей туда содержимое папки `site/`
   (включая собранный `.jar` в `downloads/`)
2. В настройках репозитория — `Settings → Pages → Source: main branch`
3. Через пару минут сайт будет доступен по адресу вида
   `https://твой-ник.github.io/имя-репозитория/`

Другие бесплатные варианты с тем же принципом — Netlify, Vercel, Cloudflare Pages
(просто перетаскиваешь папку `site/` в их веб-интерфейс).

## Как выпустить новую версию

Открой `version.json` и поменяй нужные поля:

```json
{
  "version": "0.2.0",
  "stage": "beta",
  "releaseDate": "2026-10-01",
  "jarFile": "downloads/salfvisuals-0.2.0-beta.jar",
  "changelog": [
    "Что нового в этой версии",
    "Ещё один пункт"
  ]
}
```

Положи новый `.jar` в `downloads/`, обнови `jarFile` на его имя — весь остальной
сайт (шапка, кнопка, чейнджлог) обновится сам, HTML/CSS трогать не нужно.

Когда решишь выйти из беты — просто смени `"stage": "beta"` на `"stage": "release"`.
