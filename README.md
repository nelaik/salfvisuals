# Сайт SalfVisuals

Статический сайт для GitHub Pages. Все файлы лежат в одной папке, без подпапок.

| Файл | Что это |
|---|---|
| `index.html` | главная: меню мода, возможности, установка, аккаунт, обновления, вопросы |
| `account.html` | личный кабинет: профиль, ник в Minecraft, смена пароля, выход |
| `style.css` | оформление всего сайта |
| `app.js` | общее: вход/регистрация, окно входа, уведомления, меню на телефоне |
| `home.js` | главная: живое меню мода, вкладки, обновления, небо |
| `account.js` | личный кабинет |
| `version.json` | версия мода, ссылки, список изменений, адрес сервера аккаунтов |
| `sf_logo.png`, `favicon*`, `icon-*.png`, `apple-touch-icon.png`, `site.webmanifest` | логотип и иконки |

## Как залить

1. Загрузи все файлы в корень репозитория `nelaik/salfvisuals` с заменой. Старый `script.js` больше не нужен — можно удалить.
2. Рядом положи `salfvisuals-<версия>.jar` (имя — из `jarFile` в `version.json`).
3. Через 1–2 минуты открой сайт и нажми Ctrl+F5.

## Аккаунты

GitHub Pages только раздаёт файлы — хранить пароли и проверять вход он не может. Этим занимается
бэкенд из архива `salfvisuals-backend` (там своя инструкция). Когда он запущен по HTTPS, впиши его адрес
в `version.json`:

```json
"apiBaseUrl": "https://api.твой-домен.ru"
```

Без слеша в конце. Пока поле пустое, окно входа пишет, что сервер аккаунтов ещё не подключён, —
сайт при этом полностью работает, скачивание аккаунта не требует.

Тот же адрес можно вписать в `downloadBaseUrl` — тогда кнопка скачивания пойдёт через счётчик
скачиваний бэкенда, а под кнопкой появятся честные цифры: сколько скачали и сколько аккаунтов.

## Новая версия мода

Правишь только `version.json`:

- `version`, `releaseDate` (ГГГГ-ММ-ДД), `jarFile` (`salfvisuals-<версия>.jar`);
- текущий `changelog` перенеси в начало `history` (`{ "version", "date", "changelog" }`),
  а в `changelog` впиши новое: группы `{ "title": ..., "items": [...] }`.

Если менял `style.css` или скрипты — подними номер `?v=` в `index.html` и `account.html`, иначе браузеры
могут показать старые файлы из кэша.

## Проверить у себя

Двойной клик по `index.html` не сработает (браузер не даёт читать `version.json` с диска):

```
python -m http.server 8000
```

и открой `http://localhost:8000`.
