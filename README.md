# Сайт SalfVisuals

Статический сайт: `index.html` + `style.css` + `script.js` + `version.json` + `sf_logo.png`.
Все файлы лежат **в одной папке, без подпапок**. Серверная часть не нужна.

## Как обновить сайт на GitHub Pages (репозиторий `nelaik/salfvisuals`)

1. Загрузи в **корень** репозитория с заменой все файлы из этого архива:
   `index.html`, `style.css`, `script.js`, `version.json`, `sf_logo.png`, `README.md`.
2. Рядом загрузи сам мод — файл **`salfvisuals-0.3.7.jar`**.
   Это ровно то имя, которое даёт `gradlew build` (`build/libs/salfvisuals-0.3.7.jar`), переименовывать не надо.
3. Старые `salfvisuals-0.1.0-beta.jar` / `salfvisuals-0.2.0-beta.jar` можно удалить — на них больше ничего не ссылается.
4. GitHub Pages обновляется 1–2 минуты. Если в браузере всё ещё старое — Ctrl+F5.

Почему раньше качалась 0.1.0-beta: на GitHub лежал старый `version.json` (0.1.0), а кнопка «Скачать»
берёт имя файла именно оттуда.

## Если сайт «развалился» (текст без оформления, старая версия)

Почти всегда это одно из двух:
- на GitHub остался **старый `version.json`** — тогда на странице старая версия и кнопка качает старый файл.
  Загрузи `version.json` из архива с заменой;
- браузер взял **старый `style.css` из кэша**. Теперь в `index.html` стили и скрипт подключаются с номером
  версии (`style.css?v=0.3.7`), поэтому после обновления браузер сам берёт свежие файлы. Разово помогает Ctrl+F5.

## Как выпустить новую версию

Правишь только `version.json`:

- `version` — номер версии (как `mod_version` в `gradle.properties`);
- `jarFile` — `salfvisuals-<версия>.jar`;
- `releaseDate` — дата `ГГГГ-ММ-ДД`;
- `stage` — пусто для обычного релиза (значка нет). `"beta"` — покажет значок BETA;
- `changelog` — что нового в этой версии: список групп `{ "title": ..., "items": [...] }`;
- `history` — прошлые версии `{ "version", "date", "changelog" }`, новые сверху.
  Перед выпуском новой версии перенеси текущий `changelog` в начало `history`.

`version.json` загружается без кэша, поэтому новая версия видна сразу после обновления GitHub Pages.
Если менял `style.css` или `script.js` — подними номер в `index.html` (`style.css?v=…`, `script.js?v=…`).

## Как проверить локально

Двойной клик по `index.html` не сработает: браузер блокирует `fetch()` для `file://`.

```
python -m http.server 8000
```

Потом открой `http://localhost:8000`.

## Счётчик скачиваний

Блок «сегодня / за неделю / за всё время» скрыт, пока не подключён бэкенд. Подними
`salfvisuals-downloads-backend`, впиши его адрес в `downloadBaseUrl` в `version.json` (без слеша в конце) —
кнопка начнёт вести через `/download/<jarFile>`, а цифры подтянутся с `/api/stats`.
