SalfVisuals

Клиентский мод для Minecraft: честные визуальные улучшения, гибкий HUD и ни одной функции, которая видит сквозь стены.

BETA версия — для Minecraft —
Скачать SalfVisuals .jar файл Fabric API обязательно нужен

Это бета — часть функций может работать нестабильно. Пиши о багах в Telegram — @Ne1aik.

Что внутри

HUD, который выглядит как свой

Logo, здоровье, координаты, пинг, инвентарь, броня — каждый элемент двигается мышкой, красится в общий акцент темы, у каждого своя прозрачность.

Sky

Aurora и Nebula — движущееся небо на весь купол, не только у горизонта.

Target Effect

Подсветка того, на кого ты смотришь — требует прямой видимости, не работает сквозь стены.

Полная RGB-палитра

Любой цвет любого элемента — не набор пресетов, а настоящий color picker.

Два стиля меню, RU/EN

Классическое меню или новое мультиколоночное — переключается на лету. Язык интерфейса — тоже.

Custom Trails

Волнистый светящийся след позади игрока при движении.

Установка

  1. 1

    Поставь Fabric Loader

    Через официальный установщик Fabric, версия Minecraft — 1.21.4.

  2. 2

    Скачай Fabric API

    Без него мод не запустится. Кнопка выше ведёт на нужную версию.

  3. 3

    Скачай SalfVisuals

    Кнопка выше — salfvisuals-0.1.0-beta.jar.

  4. 4

    Закинь оба файла в mods

    %appdata%\.minecraft\mods — и Fabric API, и SalfVisuals должны лежать там рядом.

  5. 5

    Запусти игру через профиль Fabric

    В лаунчере выбери профиль "fabric-loader-..." — меню мода открывается по Right Shift.
